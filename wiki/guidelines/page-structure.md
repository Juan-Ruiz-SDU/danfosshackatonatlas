# Why
AI search engines (Google AI Overviews and AI Mode, Bing, Perplexity) split a page into passages and pick the passages that best answer each sub-question. A passage that starts with a clear heading and answers one topic on its own is easier to find and to cite than the same facts spread over a long text.

# Rules
- Exactly one H1: the product name.
- One H2 section per buyer topic (for example: refrigerants, capacity and sizes, double wall, selection software, testing). Put the topic words in the heading.
- Sub-topics get an H3. Do not skip levels and do not use bold text as a fake heading.
- Each section should make sense on its own, in about 150 to 300 words: repeat the product name instead of writing "it" at the start of a section.
- Start each section with the direct answer, then the detail.
- Specifications (outline, capacity, pressure, models, refrigerants) go in an HTML table or a list, never only in running text.
- State facts plainly. No hedging words ("may", "could") unless the fact sheet itself hedges.
- Say what the fact sheet does not cover instead of leaving a gap that invites guessing (for example "no pressure data in our sources").
- Format changes never change the facts: when reformatting an existing page, every sentence stays as it is.
